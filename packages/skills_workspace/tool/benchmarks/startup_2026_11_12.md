# Startup observability acceptance, 2026-11-12

This change adds local timings only. Startup already skipped full published
materialization inspection at baseline `148245bd`; no startup redesign or
performance gain is attributed to the timing patch (`1e3077d`).

## Same-condition measurements

Physical macOS arm64, macOS 27.0.1 (26A434), Dart 3.13.4 / Flutter 3.47.5.
Both revisions used the same generated temporary Workspace and committed
lockfiles, with `PUB_HOSTED_URL=https://pub.dev`. The pinned SQLite 3.5.2 native
asset was reused from the existing verified cache (SHA-256
`6d80ba56cff1fa44f62bebc3e6b6b71513cc628862a9745c223c7bea8bf813f3`).

The fixture has 85 Managed Skills, 340 copy-mode Activations, 425 published
artifacts, 4,250 files and 49,314,100 bytes. Each run creates a new facade,
opens it, captures its authoritative catalog, then closes it. One first open
and five warm opens are reported. Projection manifests are read **outside**
the timed region, warming filesystem caches; these are not machine-cold
measurements. Process launch and native compilation are excluded.

| Boundary / mode | Baseline median | Patch median |
| --- | ---: | ---: |
| `repository.open`, Dart JIT, five warm opens | 714.480 ms | 756.659 ms |
| `repository.open`, Dart AOT product, five warm opens | 944.416 ms | 931.021 ms |
| Native App Debug, mount to first rendered Installed row | 1,062.671 ms | 1,091.071 ms |

First native Debug mounts were 2,885.656 ms (base) and 2,228.250 ms (patch).
The native App test mounts the actual `SkillsManagerApp`, production package
adapter and Snapshot provider, with generated Workspace/Agent paths and memory
settings. It measures first rendered catalog rows after `pumpWidget`, excluding
native process/bootstrap time. Debug UI results are not packaged Release launch
latency. Timing differences are observations, not a claimed speedup; no cache
purge, device reboot or controlled background-load protocol was used.

The patch AOT warm `revisionMaintenance` phase median was 860.758 ms,
`revisionReferenceReconciliation` 58.746 ms and `snapshotRead` 6.447 ms.
Mandatory maintenance still calls `verifyStore` for each selected Store and
reads one upstream tree, plus the Effective tree when distinct. It is not a
zero-read startup. Deterministic adapter tests separately record one Store
verification and one/two tree reads; startup tests retain all 85 maintenance
calls and record zero published-materialization reconciliation calls.

## Validation and data integrity

The patch AOT single-Skill request checked one Skill / five artifacts /
50 files / 540,460 bytes and repaired zero artifacts. Explicit full validation
checked all 85 Skills / 425 artifacts / 4,250 files / 49,314,100 bytes; all were
healthy and zero artifacts were repaired. Its measured duration was 1,362.673 ms
(baseline 1,325.772 ms). Unit tests also cover coalesced callers, cancellation
at the four-worker bound, two-pass missing repair, drift preservation, invalid
selection, authoritative corruption and redaction on exceptions.

Across base/patch JIT/AOT and native UI checks, catalog identity/revision
pointers and projection contents, entry types, permissions, sizes and mtimes

The opt-in physical macOS App integration test passed once on each revision.
Package format and strict analysis passed. The final focused startup,
validation and maintenance command passed 34 tests; the separate focused
recovery/drift/facade command passed 65 tests (overlapping coverage). App strict
analysis passed. Whole-package coverage and native suites are separate combined
validation gates. Windows/Linux filesystem behavior, packaged Release first

and Dart's local developer logging stream; Timeline events remain available.

fixed phase names, durations, boolean outcomes and numeric counters only.
