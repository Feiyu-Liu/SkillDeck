1. The existing CSP blocks scripts. The maintainer approved **only a fixed
   script SHA-256 allowlist on `/app/sign-in`**. The browser test verifies the
   hash matches the script, and actual form submission works with CSP enabled.
2. T43's claim that accepting a new source preserves old local history was
   false. Workspace's replacement planner deletes old Source Lineages. The
   maintainer approved keeping that behavior and changing confirmation N to:
   - EN: "This device's unsynced changes and previous history will be removed
     and replaced by the new source's history."
   - ZH: "这台设备上未同步的更改和原有历史记录将被移除，由新来源的历史记录代替。"
   Preservation is a separate task in
   `../follow-ups/source-replacement-history.md`. No Workspace behavior changed.
