## Capture method

macOS 27.0.1, Flutter 3.50.0; actual App shell and fonts, 800×600 native window (800×568 content). Synthetic data, the existing FakeCloudService/FakeSkillsWorkspaceRepository and in-memory sessions. No product behavior or styling changes. Native semantics publication is disabled only in capture bindings because the rapid-root-replacement harness triggered a Flutter native AX traversal crash; this is not an accessibility acceptance run.

Run from `skilldeck-app/`:

```sh
flutter test --no-pub -d macos \
  --dart-define=SKILLDECK_CLOUD_UI_CAPTURE=true \
  --dart-define=SKILLDECK_CAPTURE_DIRECTORY=<checkout>/branch-doc/screenshots/T39 \
  integration_test/cloud_ui_capture_test.dart
```

For a focused recapture, `--dart-define=SKILLDECK_CAPTURE_ITEM=new-device` replaces that item’s manifest entries and preserves other captured items. `capture-inventory.json` records rendered text, icon labels, and visible AppButton actions. The text below is matched to the current ARB values; sample email/Skill/note content is synthetic data, not localization copy.
